Crystal Forge — Help

Crystal Forge is a browser-based 3D crystal cluster design tool. Use the three workspaces to sketch, refine and export stylised crystals.

Getting started

  1. Open Design. Choose a growth pattern, quantity and size. Drag the scene to orbit and use the scroll wheel to zoom.
  2. Use Spacing / overlap to make the crystal roots intersect more or less, and Angle randomness to vary the growth tilt.
  3. Top / bottom diameter controls crystal taper; keep side-corner rounding low and use a tiny Tip end rounding for crisp, softened points.
  4. Click a crystal in the 3D scene or Object tree. Choose a transform tool to reveal the coloured X/Y/Z handles.
  5. In Build, choose a fitted, square, circular, rounded, organic or miniature crystal-crust base. Adjust its extra width independently of height.
  6. Use One pixel · shared glowing cluster for the balloon-like hollow enclosure with one underside pixel access hole. Then Print → Prepare print mesh to export the merged shell.

Crystal size, extreme taper and rigid lean

Use Crystal starting size for overall thickness (not height). Bottom and top widths use signed percentages: +100% doubles an end and -50% halves it. Width randomness adds repeatable independent variations; leaning rigidly tilts each entire crystal. The entire root perimeter is embedded in the dome to prevent exposed lower corners.

Individual crystal shaping

Click a crystal or select it from the tree. It turns green (or red when locked). The same crystal-shape controls on the left switch to INDIVIDUAL CRYSTAL scope and only affect the selection. Use Edit all crystals to return to global adjustments, or Reset individual overrides to restore inheritance.

Simple and Advanced

Switch modes at any time. Simple keeps the main controls visible; Advanced reveals precision shaping, transforms and mounting presets. Switching does not regenerate your model.

Mouse and view controls

  • Left-drag on empty space: orbit camera. Scroll: zoom. Right-drag: pan.
  • ISO, FR, BK, LT, RT, TOP, BOT: standard camera views, including a direct underside inspection.
  • Floating: hide the print-bed grid and orbit around the full object freely. Right-drag to pan.
  • Move / Rotate / Scale reveal gizmos: red X, green Y, blue Z.
  • Grid toggles the floor grid. Hardware IDs outlines LED bores in yellow and mounting inserts in purple on a prepared mesh. These annotations are not included in STL/3MF.
  • Solid / Wire / X-ray change inspection mode.

Keyboard shortcuts

V Select · G Move · R Rotate · S Scale · F Focus selected · Del Delete · Ctrl + Z Undo · Ctrl + Y Redo · Esc Deselect or close this panel.

Saving and reopening

Projects are automatically saved in this browser. ↓ Save downloads a portable JSON project. ↑ Open restores it. STL export contains only the 3D surface geometry; editable controls are preserved in JSON.

PR7: Physical light and fabrication updates

Build supports optional targeted bores from LED openings into eligible crystal roots, instead of slow full hollowing. Manual LED holes may use individual measured housing profiles. Print downloads a stepped physical fit coupon, a separate registered M3 mounting plate and a production ZIP including valid modular assembly parts. Confirm actual light paths, mechanical strength and printer compatibility in Cura and physical prints.

PR6: Combined development phases

Apply crystal shaping presets in Design; use Build grid snapping and optional test-fit LED retention; in Print download Cura checklists, an optical access audit, split dowel STLs and a production ZIP after preparing a valid mesh. These tools cannot certify safe printed parts or actual light paths. Review the full remaining acceptance work in docs/PR6_ALL_PHASES.md on GitHub.

PR5: Cura printing profiles

In Print, choose the correct Ultimaker machine and physical nozzle, PLA/PETG, Fast-to-Fine quality and the target translucent/structural intent. Download a .curaprofile quality-change file and import it using Cura → Preferences → Configure Cura → Profiles → Import after selecting the matching printer/nozzle and material. 0% infill is not an optical channel guarantee. Ultimaker 3 Extended standard AA 0.6 is not available, so that combination is disabled. Review layer and support details and physically test print fittings.

PR5: wiring, printing and the implementation queue

Build → underside wire channels can carve real open-bottom grooves between accepted LED sockets. Use optional perimeter exit and advanced width/depth/slack settings; cyan lines mark the accepted routes and Print exports a wiring CSV. These do not provide enclosed conduits, reliable strain relief or assured light transmission. In Print, enter custom machine build limits or inspect the approximate worst-case zero-infill roof-span indicator (always verify in Cura). The full phased backlog is documented on GitHub in docs/PR5_MASTER_IMPLEMENTATION_PLAN.md.

PR4: Pixel profiles, help and dome modes

Build → Base profile chooses flat, plinth+dome or full hill. Dome falloff controls the spread; side wall amount controls how closely the hill reaches the floor. Use ⓘ Descriptions for a persistent panel explaining settings, including each mounting preset. The Pixel profile editor saves measured body, flange, dome and wire relief values for actual socket cutters. Saved profiles are included in portable JSON. Retention clips and full wire routing still require further design.

LEDs, hollowing and Print preparation

Build defaults to one 12 mm nominal pixel push-fit in the underside, adjustable fit, a common air chamber with passages to eligible crystals, and separate screw/magnet/M3 mounting features. Mounting holes are moved away from pixel openings or skipped if there is insufficient clearance. The preview is lightweight; click Print → Prepare print mesh to build the real Boolean manufacturing model, review support-risk warnings and export Z-up STL/3MF. Target wall thickness starts at 1.2 mm and the overhang screening angle defaults to 45°. Those values are starting points, not guarantees.

Printer fit & calibration

In Print, choose your Ultimaker profile and inspect the size comparison. Download a five-hole LED calibration strip (11.8–12.2 mm) and print it in your actual filament to find an appropriate tolerance. Cutting a 12 mm hole does not guarantee that a 12 mm pixel will fit.

Cutting a model into parts

Advanced mode supports a manual X-axis cut plane and exports each manifold half as a separate STL. It does not yet add matching dowel connectors or complete assembly drawings.

Fabrication warning: Use Print → Prepare Print for a Boolean-unioned, topologically validated manufacturing mesh. Hollowing is an approximate inset; LED sockets require fit calibration; unsupported regions need review in Cura before physical printing.
